# بوت ماسنجر بقوائم أزرار

بوت بسيط لمنصة فيسبوك ماسنجر: يستقبل أي رسالة من المستخدم ويرد بقائمة أزرار (Buttons Menu)، وعند الضغط على أي زر يعطي رد مناسب.

## الملفات
- `index.js` — كود السيرفر والبوت
- `package.json` — قائمة المكتبات المطلوبة
- `.env.example` — نموذج لمتغيرات الإعداد (انسخه لملف `.env` واملأه ببياناتك)

## خطوات التشغيل

### 1. إعداد تطبيق فيسبوك
1. روح لـ [developers.facebook.com](https://developers.facebook.com) وسوّي حساب مطور
2. أنشئ **App جديد** من نوع **Business**
3. من لوحة التطبيق، أضف منتج **Messenger**
4. اربط **صفحة فيسبوك** خاصة بك بالتطبيق
5. من قسم Messenger، ولّد **Page Access Token** واحفظه

### 2. تثبيت المشروع محلياً
```bash
npm install
```

### 3. إعداد المتغيرات
انسخ ملف `.env.example` وسمّه `.env`، واملأ فيه:
- `VERIFY_TOKEN` — أي كلمة سرية تختارها بنفسك (تحتاجها بالخطوة القادمة)
- `PAGE_ACCESS_TOKEN` — الرمز اللي حصلت عليه من فيسبوك

### 4. تشغيل السيرفر
```bash
npm start
```

### 5. رفعه على استضافة (لازم رابط HTTPS عام)
البوت لازم يكون على رابط يشتغل دايماً على الإنترنت (فيسبوك ما يقدر يوصل لجهازك الشخصي مباشرة). خيارات سهلة ومجانية للبداية:
- [Render](https://render.com)
- [Railway](https://railway.app)

بعد الرفع، خذ رابط السيرفر (مثلاً: `https://your-app.onrender.com`)

### 6. ربط الويب هوك بفيسبوك
1. ارجع للوحة تطبيق فيسبوك → قسم Messenger → **Webhooks**
2. اضغط **Add Callback URL**
3. **Callback URL**: `https://your-app.onrender.com/webhook`
4. **Verify Token**: نفس القيمة اللي حطيتها في `.env`
5. فعّل الاشتراك في حدث **messages** و **messaging_postbacks**

### 7. جرّب البوت
روح لصفحة الفيسبوك تبعتك واكتب أي رسالة في ماسنجر — لازم يرد عليك بقائمة الأزرار.

## تخصيص البوت
- عدّل نص ونوع الأزرار في دالة `sendButtonMenu` داخل `index.js`
- عدّل الردود في دالة `handlePostback` حسب احتياجك
- تقدر تضيف أزرار أكثر (الحد الأقصى 3 أزرار لكل قالب من نوع button template)
